# Отметка посещаемости

Небольшой сайт для самостоятельной отметки студентов. Сервер не использует сторонних пакетов: раздаёт файлы из `public/`, принимает отметки и сохраняет их в `data/attendance.json` (эта папка не попадает в Git).

## Запуск

Требуется Node.js 18 или новее.

```powershell
npm start
```

Сайт откроется по адресу `http://localhost:3000`.

Чтобы включить панель преподавателя, до запуска обязательно задайте PIN из 4–64 цифр:

```powershell
$env:ADMIN_PIN = "4829"
npm start
```

В macOS/Linux:

```bash
ADMIN_PIN=4829 npm start
```

Без `ADMIN_PIN` публичная отметка работает, но вход преподавателя намеренно отключён. Не используйте простой PIN в сети, доступной студентам.

Необязательные настройки среды:

| Переменная | По умолчанию | Значение |
| --- | --- | --- |
| `PORT` | `3000` | Порт сервера. |
| `HOST` | `0.0.0.0` | Адрес, на котором слушает сервер. |
| `DATA_DIR` | `data` | Папка для `attendance.json`; не задавайте путь внутри `public/`. |
| `ADMIN_PIN` | — | Обязателен для панели преподавателя; 4–64 цифры. |
| `ADMIN_SESSION_TTL_MINUTES` | `480` | Время жизни токена преподавателя, от 5 до 1440 минут. |
| `KZ_TIME_ZONE` | `Asia/Qyzylorda` | Часовой пояс, по которому определяется дата отметки. |
| `TRUST_PROXY` | `false` | Установите `true` только за доверенным reverse proxy, чтобы учитывать `X-Forwarded-For` в лимитах. |

## API для интерфейса

Все JSON-запросы должны отправляться с `Content-Type: application/json`.

`GET /api/status`

Возвращает серверную дату Казахстана:

```json
{ "dateKey": "2026-09-20", "dateLabel": "20 сентября 2026 г." }
```

`POST /api/attendance`

```json
{
  "fullName": "Иванов Иван Иванович",
  "group": "ИТ-23-1",
  "deviceId": "сгенерированный_в_браузере_стойкий_токен"
}
```

Интерфейс должен сгенерировать `deviceId` один раз (например, `crypto.randomUUID()`) и хранить его в `localStorage`. Сервер хранит только SHA-256-хеш этого значения. Повторная комбинация нормализованных ФИО + группы в тот же серверный день или повтор с того же устройства вернёт `409` с русским сообщением.

`POST /api/admin/login`

```json
{ "pin": "4829" }
```

Возвращает короткоживущий `token`. Для следующих защищённых запросов передавайте заголовок `Authorization: Bearer TOKEN`. Токен храните только в памяти вкладки, не в `localStorage`.

`GET /api/admin/attendance?date=YYYY-MM-DD`

Возвращает отчёт вида:

```json
{
  "dateKey": "2026-09-20",
  "dateLabel": "20 сентября 2026 г.",
  "total": 2,
  "groups": [
    {
      "group": "ИТ-23-1",
      "total": 2,
      "students": [
        { "id": "…", "fullName": "Иванов Иван Иванович", "markedAt": "2026-09-20T04:15:00.000Z" }
      ]
    }
  ]
}
```

Если `date` не указан, используется текущая дата Казахстана.

`GET /api/admin/export?date=YYYY-MM-DD`

Те же права доступа; возвращает CSV с UTF-8 BOM для корректного открытия в Excel. Значения экранируются от CSV-формул.

## Ограничения защиты

Сервер нормализует пробелы, регистр, дефисы и `ё/е`, поэтому случайные варианты одного ФИО не создадут второй отметки. Дополнительно действует ограничение частоты запросов и одна отметка на токен устройства в день.

Однако без заранее загруженного списка студентов, кода студента или авторизации невозможно надёжно отличить человека, который назвался чужим ФИО, от настоящего студента. Для строгой идентификации следует добавить реестр студентов и личный код/вход.

`data/attendance.json` рассчитан на один постоянно работающий экземпляр сервера с постоянным диском. Не запускайте несколько копий приложения с одним файлом данных и не используйте ephemeral-хостинг без внешней базы данных.
